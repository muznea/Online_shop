HAFSWA ONLINE SHOP - PHP 8 + MySQL (XAMPP)
1. Copy this folder to C:\xampp\htdocs\hafswa-shop2
2. Open XAMPP Control Panel and START Apache and MySQL.
3. Open http://localhost/hafswa-shop (database 'hafswa_shop' and all tables + sample products are created automatically; see them in http://localhost/phpmyadmin)
4. Open http://localhost/hafswa-shop/admin.php and register your admin account (first time only).
DB settings (host/user/password/name) are at the top of config.php. XAMPP default: user root, empty password.
WhatsApp number: WA in config.php (format 255XXXXXXXXX).
